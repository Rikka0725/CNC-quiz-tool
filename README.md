# 数控技术刷题 · 使用说明

## 一、交付文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件刷题页面，内嵌全部题库，无任何外部网络依赖，手机浏览器直接打开即可使用 |
| `bank.json` | 提取后的题库数据（170 题），便于后续校对与维护 |
| `说明.md` | 本文件 |

## 二、使用方法

1. 把 `index.html` 发送到手机（微信/QQ 传文件、网盘下载均可），用浏览器打开。
2. 建议在浏览器菜单中选择「添加到主屏幕」，之后可像 App 一样全屏使用。
3. 首次打开直接进入首页：`开始刷题`、`收藏题目`、`错题本`、`清空记录`。

## 三、功能说明

- **开始刷题**：先选择题型（单选题 130 道 / 判断题 40 道 / 全部 170 道），再选顺序刷或随机刷。
- **即时判定**：点选选项后立即显示「回答正确 / 回答错误」与正确答案，正确项绿色、错选项红色。
- **逐题浏览**：底部「上一题 / 下一题」，最后一题显示「完成」，进入本次练习结果页（正确率、题量、已答、答对）。
- **进度与得分**：顶部显示当前第几题/总题数及进度条，底部显示本次「已答 / 答对」。
- **收藏**：答题页右上角 ☆ 可收藏/取消收藏；首页「收藏题目」可查看、逐题练、清空。
- **错题本**：答错自动收录；之后答对会自动移出；也可手动移除或清空。
- **保存进度**：进度、错题、收藏、累计统计均存于浏览器 `localStorage`，关闭页面不丢失；首页出现「继续上次」可接着刷。

存储键：`cncquiz.session`（当前进度）、`cncquiz.wrong`（错题）、`cncquiz.fav`（收藏）、`cncquiz.stats`（累计答题与正确率）。

## 四、题库数据说明

`bank.json` 结构：

```json
{
  "meta": { "singleCount": 130, "judgeCount": 40, "total": 170 },
  "questions": [
    { "id": "s66", "type": "single", "no": 66,
      "stem": "某加工程序中的一个程序段为 …",
      "options": ["…", "…", "…", "…"], "answer": "B" }
  ]
}
```

- `id`：题目标识，`s` + 单选题号 / `j` + 判断题号。
- `type`：`single` 单选、`judge` 判断。
- `no`：原题题号（单选 1–130，判断 1–40）。
- `options`：选项文本，不含 A/B/C/D 前缀；判断题固定为 `["正确","错误"]`。
- `answer`：单选为字母 `A/B/C/D`；判断为 `正确` 或 `错误`。
- `image`（可选）：题图，data URI 格式；目前仅第 127 题（刀架位置示意图）使用。

## 五、提取与校对提示

1. 题库目录共 54 张截图（单选 46 张 + 判断 8 张，另有同名 PDF 内容一致），已逐张读取。单选与判断题号各自连续，题量与「单选 130 / 判断 40」一致，无缺号、无重复录入。
2. 判断题按原题形式呈现为「正确 / 错误」两个选项。
3. 原题中部分单选题只有 A、B、C 三个选项（如 s102、s105、s106、s111、s116、s120、s125、s126、s128），已按原样保留。
4. 题库中存在不同题号但内容相近的题目（如 s20 与 s92、s31 与 s109、s48 与 s106、s70 与 s126、j25 与 j34），属于原题库重复出题，已分别保留，未做合并。
5. 个别题目原文或答案存在表述瑕疵，均按原题保留，便于校对：
   - 第 127 题原题配有刀架位置示意图，已从原 PDF 中提取并以 data URI 内嵌（`bank.json` 的 `image` 字段、`index.html` 内嵌数据），离线打开也能显示。
   - 第 64 题 C 选项按原题更正为「被加工工件」（初稿误作「编程工件」）。
   - 第 62 题原文前后均为「轴向」，按题意与答案（G71）补为「轴向的车削量远大于径向时」。
   - 第 6、23、113 题等原文个别用词（如「无级调节器速成」「进速」「D21」）保持原样。
6. 页面仅内置题干、选项与答案，未包含「解析」（原题解析大多为空）。

## 六、兼容性说明

- 已按手机竖屏设计：最大宽度 560px 居中，按钮与选项点击高度不小于 50px，适配刘海屏安全区。
- 若通过某些文件管理器以 `file://` 方式打开后无法保存进度，可改用手机浏览器打开本地文件，或部署到任意静态服务器/网盘直链后访问。
