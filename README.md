# 数控技术刷题

手机端数控技术刷题网页，共 **170 题**（单选题 130 道 + 判断题 40 道）。单文件、零依赖，打开即刷，按手机竖屏优化。

**在线刷题：** `https://rikka0725.github.io/CNC-quiz-tool/`

<!-- 将上面的占位链接替换为实际的 GitHub Pages 地址 -->

## 功能

- **选择题型**：单选题、判断题、全部题目混合练习
- **两种顺序**：顺序刷 / 随机刷
- **即时判定**：点选后立刻显示「回答正确 / 回答错误」与正确答案
- **逐题浏览**：上一题 / 下一题，顶部进度条，底部本次得分
- **完成页**：本次正确率、题量、已答、答对，可一键再练
- **收藏题目**：答题页右上角 ☆ 收藏，首页可集中练习
- **错题本**：答错自动收录，之后答对自动移出，也可手动移除
- **断点续刷**：进度、错题、收藏存在浏览器本地，刷新或关闭后仍可继续

## 使用

1. 手机浏览器打开上面的在线地址（Chrome / Safari / Edge 均可）。
2. 在浏览器菜单中选择「添加到主屏幕」，之后可全屏使用。
3. 首页选择「开始刷题」，选题型与顺序即可。

## 题库数据

- 单选 1–130、判断 1–40，题号连续，无缺号；答案取自原题「正确答案」字段。
- 判断题按原题形式呈现为「正确 / 错误」。
- 第 127 题的刀架位置示意图已从原 PDF 提取，以 data URI 内嵌，离线也能显示。

`bank.json` 中每道题的结构：

```json
{
  "id": "s66",
  "type": "single",
  "no": 66,
  "stem": "题干……",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": "B"
}
```

- `id`：`s` + 单选题号 / `j` + 判断题号
- `type`：`single` 单选、`judge` 判断
- `answer`：单选为 `A/B/C/D`，判断为 `正确/错误`
- `image`（可选）：题图 data URI，目前仅第 127 题使用

## 关于刷题进度

进度保存在浏览器的 `localStorage` 中，属于「本机 + 本浏览器」，**不会上传到 GitHub，也不会在同学之间同步**。换手机、换浏览器或清除浏览数据后，进度会重新开始；把 `index.html` 发给别人，对方打开的也是一份全新记录。

## 更新题库

修改 `bank.json` 后，需要把数据同步写入 `index.html` 内嵌的 `var BANK = [...]` 数据段：

- 若保留了 `work/rebuild.py`，在 `work` 目录运行 `python rebuild.py` 即可自动同步；
- 也可以直接编辑 `index.html` 中对应题目，注意两份数据保持一致。

## 部署到 GitHub Pages

仓库 **Settings → Pages → Build and deployment** 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
